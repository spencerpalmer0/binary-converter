# Binary Converter

A developer tool for converting number systems.

## Features

- Decimal conversion
- Binary conversion
- Hexadecimal conversion

## How to Use

Enter a number and select its original number system.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
